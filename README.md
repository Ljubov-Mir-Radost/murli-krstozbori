# Мурли Крстозбори

Мобилна PWA апликација за решавање крстозбори на македонски јазик.

Проверена основа: верзија 16, поправка 5.

- Кирилична тастатура со автоматска проверка на одговорите.
- Прескокнување на точните букви и изборно преминување на следното прашање.
- Зачувување на напредокот на уредот.
- Офлајн работа по првото целосно отворање.
- Увоз на крстозбори од JSON.

Апликација: https://ljubov-mir-radost.github.io/murli-krstozbori/

Напредокот е локален за секоја веб-адреса и не се пренесува автоматски од Netlify.
