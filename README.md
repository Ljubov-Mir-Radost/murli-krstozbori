# Мурли Крстозбори

Мобилна PWA апликација за крстозбори на македонски јазик.

Верзија 17: автоматско преземање нови крстозбори.

Апликација: https://ljubov-mir-radost.github.io/murli-krstozbori/

- Кирилична тастатура, автоматска проверка и изборно следно прашање.
- Напредокот се зачувува локално на уредот.
- Каталогот се проверува при отворање, при враќање интернет и при враќање во апликацијата по 30 минути. Достапно е и копче за проверка.
- Новите датуми автоматски се зачувуваат за офлајн решавање.
- Архивата е групирана по година и месец.
- Постоечките датуми и рачно увезените крстозбори не се заменуваат автоматски. Корекции се внесуваат преку JSON увоз со потврда.

## Додавање нов крстозбор

1. Поставете JSON во crosswords/YYYY-MM-DD.json.
2. Додадете запис со id, file и SHA256 во catalogue.json. Скриптата update-catalogue.py го создава каталогот од датотеките во папката и проверува датуми/повторувања.
3. Зачувајте ги JSON и catalogue.json на main. GitHub Pages автоматски ги објавува. Корисниците ги добиваат при следна проверка со интернет.

Идни крстозбори не се генерираат самостојно: треба да бидат подготвени и објавени во каталогот.

Првото отворање бара интернет. Потоа зачуваните крстозбори работат офлајн. Бришење податоци од прелистувачот го отстранува локалниот напредок. Напредокот е одделен од Netlify адресата.
